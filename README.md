# RNN на чистом NumPy

Три рекуррентные языковые модели, написанные с нуля на NumPy — без PyTorch и
TensorFlow. Прямой проход, обратное распространение во времени (BPTT),
обрезка градиентов и RMSProp реализованы вручную.

Модели идут по возрастанию сложности: от предсказания следующего **символа**
к предсказанию следующего **слова** и далее к GRU, которая пишет связный
**рассказ** с завязкой, развитием и концовкой.

## Требования

```bash
pip install numpy
```

Python 3.10+ (в коде используется синтаксис `int | None`).

## Файлы

| Файл | Что это |
| --- | --- |
| `char_rnn.py` | Посимвольная vanilla-RNN: предсказывает следующую букву |
| `word_rnn.py` | Пословная vanilla-RNN с эмбеддингами: предсказывает следующее слово |
| `story_rnn.py` | GRU + `<bos>`/`<eos>`, top-p, штраф за повторы — генерация целых рассказов |
| `make_stories.py` | Генератор обучающего корпуса: собирает `stories.txt` из шаблонов |
| `sample.txt` | Небольшой демо-текст для `char_rnn` / `word_rnn` |
| `stories.txt` | Корпус из 140 коротких рассказов, разделённых пустой строкой |
| `model.npz` | Готовые веса `word_rnn.py` (словарь 252, hidden 192, embed 64) |
| `story.npz` | Готовые веса `story_rnn.py` (GRU, словарь 376, embed 96) |

## Быстрый старт

Готовые веса лежат в репозитории, так что можно сразу генерировать.

**Рассказ из готовой модели:**

```bash
python story_rnn.py story --model story.npz --sentences 12
```

**Рассказ по заданному началу:**

```bash
python story_rnn.py story --model story.npz --prompt "Жил-был старый рыбак" --out rasskaz.txt
```

**Диалог с пословной моделью:**

```bash
python word_rnn.py chat --model model.npz --words 25
```

## Обучение

**Посимвольная RNN:**

```bash
python char_rnn.py train --data sample.txt --epochs 20 --model model.npz --chat
```

**Пословная RNN:**

```bash
python word_rnn.py train --data sample.txt --epochs 30 --model model.npz --chat
```

**Рассказы (GRU):**

```bash
python make_stories.py
python story_rnn.py train --data stories.txt --epochs 40 --model story.npz
```

Корпус для `story_rnn.py` — обычный `.txt`, где рассказы разделены пустой
строкой. Свой корпус подставляется через `--data`.

## Основные параметры

**Обучение** (общее для всех трёх): `--hidden` (размер скрытого слоя),
`--seq-len` (длина фрагмента для BPTT), `--epochs`, `--lr`, `--seed`.
У пословных моделей дополнительно `--embed`, `--min-freq`, `--max-vocab`,
`--lowercase`; у `story_rnn.py` — `--cell {gru,rnn}`.

**Генерация:** `--temperature` (разнообразие), `--top-k`, а у `story_rnn.py`
ещё `--top-p` (nucleus-сэмплирование), `--repetition-penalty` и
`--no-repeat-ngram` — без последних двух RNN на длинной дистанции
скатывается в повторяющийся цикл. Форму текста задают `--sentences`,
`--paragraph` (предложений в абзаце) и `--max-words`.

Полный список — `python <скрипт> <команда> --help`.

## Чем story_rnn отличается от word_rnn

1. **Ячейка GRU вместо tanh-RNN.** У простой RNN память затухает через 15–20
   слов, а рассказу нужно помнить героя и место действия десятки предложений.
   Вентили обновления и сброса дают явный механизм «держать» состояние.
2. **Служебные токены `<bos>` / `<eos>`.** Сеть учится не только языку, но и
   форме: где завязка, где концовка, когда пора остановиться.
3. **Генерация целого текста:** подсчёт предложений, разбиение на абзацы,
   nucleus-сэмплирование и запрет повторять n-граммы.
